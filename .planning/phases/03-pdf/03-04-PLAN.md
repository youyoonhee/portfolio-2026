    - `::before` surface 패널은 트랙에 그대로 둔다.

    C. css/components.css (`@layer components`), 같은 gated media query 안:
    - D-01의 "프로젝트 목록이 같은 방향으로 함께, 80ms 늦게"를 구현하려고 상태 스타일은 블록 자신이 아니라 자식 `.keyword-title`과 `.keyword-list`에 준다. 부모 opacity가 자식의 지연을 덮지 않게 하기 위해서다. 블록 자체는 opacity를 바꾸지 않는다(UI-SPEC 의도와 같음).
    - `.keywords[data-switch="on"] .keyword-block` 규칙: `:is(.keyword-title, .keyword-list)` 대상에 `transition: opacity var(--dur-switch) var(--ease), transform var(--dur-switch) var(--ease); will-change: transform, opacity;`를 둔다. `[data-state="next"]`는 두 자식에 `opacity: 0; transform: translateY(var(--space-xl));`, 블록에 `pointer-events: none`. `[data-state="past"]`는 두 자식에 `opacity: 0; transform: translateY(calc(-1 * var(--space-xl)));`, 블록에 `pointer-events: none`. `[data-state="active"]`는 두 자식에 `opacity: 1; transform: none;`, 블록에 `pointer-events: auto`. `[data-state="active"] .keyword-list`에는 `transition-delay: var(--stagger-switch)`를 두고, 떠날 때는 0이다.
    - visibility, display, aria 속성으로 숨기지 않는다(D-03). transform과 opacity만 움직인다(D-01).

    D. js/main.js에 키워드 전환을 덧붙인다(RESEARCH 프로토타입 keyword 부분, D-05).
    - `kw = #keywords`, `stage = .keywords-stage`, `blocks = .keyword-block[]`, `mqSwitch = matchMedia('(min-width: 1024px) and (min-height: 560px) and (prefers-reduced-motion: no-preference)')`.
    - `slotSize() = (kw.offsetHeight - stage.offsetHeight) / blocks.length`. `scrollIndex()`는 `-kw.getBoundingClientRect().top / slotSize()`의 floor를 0~2로 clamp한 값이다.
    - `setActive(i)`: 인덱스가 바뀔 때만 `kw.dataset.active`와 각 블록 `dataset.state`(past/active/next)를 쓴다. 프레임마다 스타일을 쓰지 않는다.
    - 스크롤: passive scroll listener와 rAF 스로틀. 프레임당 rect 하나만 읽는다. `IntersectionObserver`로 `kw`의 교차 여부를 두어, 교차하지 않으면 스크롤 프레임을 건너뛴다(UI-SPEC 4). IO 콜백이 불릴 때는 교차 여부와 상관없이 `setActive(scrollIndex())`를 한 번 불러, 빠르게 지나가도 끝 상태가 맞게 한다.
    - 포커스 보정(D-03): `kw`의 focusin에서 대상의 블록 인덱스 i를 구한다. i가 `scrollIndex()`와 다르면 `scrollTo({ top: scrollY + kw.getBoundingClientRect().top + (i + 0.5) * slotSize(), behavior: 'instant' })`를 부른다. CSS가 smooth여도 즉시 이동해야 하므로 instant는 필수다. 그다음 `setActive(i)`를 부른다.
    - `enableSwitch()`: 먼저 `setActive(scrollIndex())`로 data-state를 쓰고, 그다음 `kw.dataset.switch = 'on'`을 둔다. 이 순서라야 첫 페인트에 트랜지션이 없다. 그리고 listener와 IO를 붙인다. `disableSwitch()`는 listener와 IO를 떼고 data-switch, data-active, 모든 data-state를 지운다. `mqSwitch` change에서 둘 중 하나를 부르고, 시작할 때도 한 번 부른다.
    - `animation-timeline`, 스크롤 위치·속도 가로채기(wheel preventDefault, 강제 snap), 진행 표시 요소 생성은 하지 않는다(D-02, D-05, design-taste W-11).
    - 숫자 배열 리터럴을 쓰지 않는다(Pitfall 7).
