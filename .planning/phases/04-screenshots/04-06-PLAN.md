## Phase Goal

**As a** 포트폴리오를 검토하는 채용 담당자, **I want to** 프로젝트마다 실제 작업 화면을 비율에 맞는 프레임으로 보고 크게 확대해 보기를, **so that** 어떤 회사에서 어떤 화면을 직접 퍼블리싱했는지 바로 파악할 수 있고, 공개된 이미지에는 민감 정보가 없다.

<objective>
여섯 번째 조각(검수): 사용자가 실제 스크린샷을 넣고, Claude가 가릴 곳과 alt를 제안해 마스킹된 미리보기를 만들고, 사용자가 그 결과를 승인한다. 이 plan은 공개 폴더를 건드리지 않는다. 승인된 것만 04-07에서 공개된다. 이미지가 없으면 빈 상태로 끝난다.

Purpose: SHOT-02 검수 체크리스트와 사람 승인 게이트, SHOT-01 실제 화면 준비, D-01, D-02, D-03, D-10, D-11, D-12, D-13.
Output: 매니페스트의 draft 항목(또는 빈 매니페스트), `dist/shots-preview/`의 마스킹 미리보기(git 제외).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User originals (PII possible) -> Claude review | Claude sees unmasked content to find regions |
| Claude review -> public artifacts (manifest, SUMMARY, commits, chat) | Only kinds, coordinates and general locations may cross |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-26 | Information disclosure | Masked text echoed into manifest, SUMMARY, commit message or chat | mitigate | Task 2 step 7 rule: kind + coordinates + general location only; strict manifest schema has no free-text field; hasPhone scan on manifest in `npm run check` |
| T-04-27 | Information disclosure | Original file names (may contain names) in the public manifest | mitigate | `source` must be ASCII kebab; non-kebab originals are copied to `<id>.<ext>` inside the gitignored folder |
| T-04-28 | Information disclosure | Publishing before approval | mitigate | All entries stay `draft`; previews only under gitignored `dist/`; acceptance asserts index.html unchanged and check-images 0 projects |
| T-04-29 | Information disclosure | Admin/internal or unclear screens | mitigate | D-11 checklist; unclear cases asked in the Task 3 checkpoint; admin screens not used |
| T-04-30 | Information disclosure | Missed region | mitigate | User checks the masked 1920/1080 preview and the numbered grid (checklist item 7) before approval |
