## Phase Goal

**As a** 포트폴리오를 검토하는 채용 담당자, **I want to** 프로젝트마다 실제 작업 화면을 비율에 맞는 프레임으로 보고 크게 확대해 보기를, **so that** 어떤 회사에서 어떤 화면을 직접 퍼블리싱했는지 바로 파악할 수 있고, 공개된 이미지에는 민감 정보가 없다.

<objective>
마지막 조각: 사용자가 승인한 스크린샷이 실제로 사이트와 제출용 PDF에 들어가고, 전체 검사와 사용자의 화면 확인을 통과한다. 승인된 이미지가 없으면 빈 프레임 상태로 같은 검사를 통과하고 도구는 나중에 다시 돌릴 수 있게 남는다.

Purpose: SHOT-01~04와 PDF-05를 실제 데이터로 닫는다. D-03, D-10, D-13, D-14.
Output: approved 매니페스트 항목, img/projects 파일, 채워진 figure, 실측 PDF 용량과 쪽 수.
</objective>
