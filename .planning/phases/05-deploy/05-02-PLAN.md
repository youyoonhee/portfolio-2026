Render contract for `dd[data-measured="<key>"]` inner HTML (colophon-sync is the only writer):
- browsers: `<ul>` with one `<li>` per entry. tested true + headless -> `{name} {version} · 확인함 (자동화 점검)`; tested true + real-device -> `{name} {version} · 확인함`; tested false + real-device -> `<span class="colophon-pending">{name} · 실기기 확인 전</span>`; tested false + headless -> `<span class="colophon-pending">{name} · 확인 전</span>`.
- lighthouse: if form or any of the four scores is null -> `<span class="colophon-pending">측정 전</span>`. Else `<ul>` with `<li><span lang="en">Performance</span> <data value="N">N</data></li>`, same for Accessibility, Best Practices, SEO; then `<li>측정 환경: {form}</li>`; then, only when crawlableFailed is true, `<li>SEO는 검색 비노출 설정(noindex)으로 감점</li>`.
